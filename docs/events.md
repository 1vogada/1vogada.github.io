# Event catalogue

Generated by reading `src/core/events.js` (the catalogue) and every `bus.emit` / `bus.on` under `src/`. The bus is synchronous:
`emit` runs every listener before it returns, in registration order. Actors register in their `install`, `src/reactions.js`
after all actors, so an actor's own listener always runs before a reaction. "Line" means a speech bubble (`say`, `sayAt`,
`speak`); each shown line draws one `Math.random` for the pick (none for a one-line list) and one for the tilt.

Re-check after a change: `grep -rn "emit('" src` and `grep -rnE "bus\.on\(|when\('" src`.
